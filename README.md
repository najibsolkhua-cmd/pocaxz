# Job Radar

Мини-CRM для поиска работы в РФ. Фоновые сборщики обходят Telegram, VK, HH, Habr Карьеру
и карьерные сайты компаний, а приложение показывает вакансии, подходящие под профиль
пользователя, и ведёт статусы откликов.

Архитектура, схема БД, подходы к источникам, матчинг и roadmap MVP описаны
в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
