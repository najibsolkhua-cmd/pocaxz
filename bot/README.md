# Бот solk / job (Telegram)

Делает две вещи:

1. **Поддержка 24/7.** Отвечает на любой вопрос о solk / job по базе знаний
   (`knowledge/faq.md` и `README.md` проекта).
   - **С ключом Claude API** отвечает своими словами, учитывает уточняющие вопросы и
     не выдумывает того, чего нет в базе. Модель — `claude-opus-5-5` с низким
     усилием (короткие ответы). База знаний кешируется (prompt caching), поэтому
     каждый вопрос стоит дёшево. Если модель отказывается отвечать, сервер сам
     повторяет запрос на запасной модели (`fallbacks: "default"`).
   - **Без ключа** присылает подходящие разделы базы знаний.
2. **Уведомления.** Расширение присылает сюда новые подходящие вакансии.
   - Привязка без паролей. Расширение открывает `t.me/<бот>?start=<случайный токен>`,
     пользователь жмёт «Запустить», бот запоминает чат.
   - Токен бота в расширение не попадает: сообщения отправляет только этот сервер.

## Запуск

1. **Создайте бота.** В Telegram откройте @BotFather → `/newbot`. Получите токен,
   затем `/setdescription`, `/setuserpic` и `/setcommands`:
   ```
   start - Начать
   help - Что умеет бот
   stop - Отключить уведомления
   new - Новый вопрос (забыть диалог)
   ```
2. **Запустите сервер.** Нужен Node 20+:
   ```
   cd bot && npm ci
   TELEGRAM_BOT_TOKEN=... ANTHROPIC_API_KEY=... npm start
   ```
   Или через Docker из корня репозитория:
   ```
   docker build -f bot/Dockerfile -t solk-bot .
   docker run -d --restart=always -e TELEGRAM_BOT_TOKEN=... -e ANTHROPIC_API_KEY=... \
     -p 8787:8787 -v solk-bot-data:/data solk-bot
   ```
3. **Откройте HTTPS-адрес для API.** Например, `https://bot.solk-job.ru` → `localhost:8787`
   через Caddy: одна строка `bot.solk-job.ru { reverse_proxy localhost:8787 }`.
4. **Пропишите бота в расширении.** В `extension/config.js`:
   `telegram.botUsername` (без @) и `telegram.botApi` (HTTPS-адрес из шага 3).
   Выпустите новую версию. После этого кнопка «/ поддержка» ведёт в бота, а в
   настройках появится «Подключить Telegram».

**Важно про Claude API.** Он недоступен из России: ни для российских аккаунтов, ни с
российских серверов. Сервер бота с ключом нужно размещать в стране, где Claude API
доступен, а оплачивать — картой, которую принимает Anthropic. Без ключа бот работает
где угодно, в режиме базы знаний.

## Обновить ответы бота

Правьте `knowledge/faq.md` и перезапустите бота. Всё, что есть в файле, бот знает.
Добавили функцию в расширение — добавьте строчку в базу.

## API для расширения

| Метод | Что делает |
|---|---|
| `GET /api/link-status?token=…` | Возвращает `{ linked, name }`. |
| `POST /api/notify` `{ token, title, items:[{title, company, score, url}] }` | Отправляет сообщение в чат: до 10 вакансий, до 30 сообщений в час на токен. |
| `POST /api/unlink` `{ token }` | Отвязывает чат. |
| `GET /health` | Проверка, что сервер жив. |

Тесты: `npm test`.
