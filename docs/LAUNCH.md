# Как запустить solk / job для всех

Цель: человек переходит по одной ссылке, нажимает «Установить», и всё работает.
Обновления приходят сами, проект бесплатный, доход — с рекламы РСЯ.

## 1. Что из чего состоит

| Часть | Где в репозитории | Зачем |
|---|---|---|
| **Расширение** | `extension/` | Сама CRM. Должна быть расширением, а не сайтом: только расширение может открывать hh.ru, Avito и сайты компаний в браузере пользователя, с его входами и IP. Обычный сайт этого не может (браузер запрещает читать чужие сайты). |
| **Сайт-переходник** | `site/` | Одна ссылка для всех: кнопка «Установить» сама ведёт в нужный каталог для браузера. Здесь же политика конфиденциальности и страница с блоком РСЯ (`ad.html`). |
| **Telegram-бот** | `bot/` | Поддержка 24/7 по базе знаний (с ИИ или без) и уведомления о новых вакансиях. |

Связь между частями — в `extension/config.js`: адрес сайта, бот, режим рекламы.

## 2. Официальная публикация и автообновления

Подробная инструкция по каждому каталогу, тексты и картинки — в [store/README.md](../store/README.md).

Яндекс Браузер ставит расширения из **каталога Opera Add-ons** (на странице расширения
есть кнопка «Добавить в Яндекс Браузер») и из **Chrome Web Store**. Расширения из
каталогов обновляются сами. Распаковывать ничего не нужно.

| Каталог | Для кого | Стоимость | Что важно |
|---|---|---|---|
| **Opera Add-ons** (addons.opera.com) | Яндекс Браузер, Opera | бесплатно | Главный для России. Ручная модерация, обычно от нескольких дней до пары недель. |
| **Chrome Web Store** | Chrome, Яндекс Браузер | $5 один раз | Нужна карта, которую принимает Google (российские карты, как правило, нет). |
| **Microsoft Edge Add-ons** | Edge | бесплатно | Необязательно, но охват шире. |
| **Каталог «Дополнения» Яндекс Браузера** | Яндекс Браузер | — | Курируемая подборка Яндекса: сюда попадают по решению Яндекса. Можно написать им после публикации в Opera. |

**Как выпускать обновления (патчи):**

1. Поменяйте код и увеличьте `version` в `extension/manifest.json` (например, 0.9.0 → 0.9.1).
2. `npm test && npm run test:e2e && npm run pack`.
3. Загрузите `dist/solk-job-<версия>-store.zip` в кабинет каждого каталога.
4. После модерации браузеры пользователей обновят расширение сами, обычно в течение
   нескольких часов. Данные пользователей при обновлении сохраняются.

Своё «сервер-обновлений» для обычных пользователей сделать нельзя: Chrome и Яндекс
Браузер на Windows и macOS разрешают автообновление только из каталогов.

**Что приготовить для каталогов:**

- **Описание** (короткое и полное). Скриншоты 1280×800: `docs/img/home.png`,
  `docs/img/searching.png` и др. Иконка 128×128: `extension/icons/icon128.png`.
- **Ссылка на политику конфиденциальности:** `https://<ваш-домен>/privacy.html`.
- **Объяснение разрешений.** Модераторы спрашивают о каждом. Готовые формулировки:
  - доступ ко всем сайтам — расширение читает списки вакансий с hh.ru, Avito,
    Telegram и любых сайтов компаний, которые добавил пользователь;
  - `tabs` и `scripting` — открыть страницу выдачи в фоновой вкладке и прочитать
    вакансии;
  - `storage` — хранить профиль и вакансии локально;
  - `alarms` — поиск по расписанию;
  - `notifications` — уведомления о новых вакансиях;
  - `offscreen` — читать сайты, закрытые для вкладок расширения.
- **Раскрытие рекламы.** В описании честно напишите: «Во время поиска показывается
  рекламный блок Яндекса». Правила каталогов разрешают рекламу в собственном интерфейсе
  расширения. Запрещено встраивать рекламу в чужие сайты; мы этого не делаем.
- **Single purpose.** Одно назначение: поиск работы и учёт откликов.

## 3. Сайт-переходник

1. Купите домен (например, `solkhua.ru`). Для РСЯ нужен собственный домен, а не
   бесплатный поддомен.
2. Разместите папку `site/` на любом статическом хостинге: GitHub Pages, Яндекс Object
   Storage, любой VPS с nginx.
3. В `site/config.js` впишите ссылки на каталоги, когда расширение опубликуют. Пока их
   нет, кнопка скачивает `site/downloads/solk-job.zip` (его собирает `npm run pack`) и
   показывает шаги ручной установки.
4. В `extension/config.js` поменяйте `siteUrl` и `ads.frameUrl` на свой домен.

**Ссылка для всех — адрес сайта.** Кнопка сама определяет браузер:
- в Яндекс Браузере — «Добавить в Яндекс Браузер» (каталог Opera);
- в Chrome — Chrome Web Store;
- в Edge — Edge Add-ons;
- на телефоне — подсказка открыть сайт на компьютере.

## 4. Реклама РСЯ: как зарабатывать, оставаясь бесплатными

**Как устроено.** В расширении во время поиска на месте часов и имени появляется
рекламная карточка (см. `docs/img/searching.png`). Правила Manifest V3 запрещают
загружать в расширение чужие скрипты, поэтому блок РСЯ стоит на вашем сайте
(`site/ad.html`), а расширение показывает эту страницу во фрейме.

**Сейчас включена заглушка** (`ads.mode: 'stub'`): демо-объявления с пометкой
«Реклама · пример», чтобы проверить механику и вёрстку.

**Подключение после юридической части:**

1. Оформите статус для выплат: самозанятый, ИП или юрлицо.
2. Зарегистрируйтесь в Рекламной сети Яндекса (partner.yandex.ru) и добавьте сайт.
   - РСЯ проверяет площадку: собственный домен, полезный контент и посещаемость.
     Требования к посещаемости в разных источниках разные, точные — в справке
     partner.yandex.ru.
   - Поэтому сначала нужен живой сайт с аудиторией.
3. Создайте RTB-блок (например, адаптивный, 600×350) и получите `blockId` вида
   `R-A-1234567-1`.
4. Впишите его в `site/config.js` → `rsyaBlockId`.
5. В `extension/config.js` поставьте `ads.mode: 'rsya'` и выпустите обновление.
6. **До запуска** напишите в поддержку РСЯ и опишите схему: «блок на моём сайте,
   показывается во фрейме внутри моего браузерного расширения». Правила площадок РСЯ
   могут ограничивать показ во фреймах, и это нужно подтвердить письменно.
   - Если такую схему не одобрят: рекламу размещают на самом сайте-переходнике и в
     Telegram-боте, а в расширении остаётся спонсорская карточка (прямые договоры с
     рекламодателями).

**Маркировка рекламы (закон о рекламе, ОРД, erid).** Объявления РСЯ Яндекс маркирует
сам: пометка «Реклама», рекламодатель, токен erid. Прямую рекламу, которую вы продаёте
сами, нужно маркировать самостоятельно через ОРД.

### Партнёрские баннеры (плитка справа внизу)

Здесь можно размещать сколько угодно партнёрских предложений: онлайн-школы, банки,
карьерные сервисы, партнёрки Яндекса. Баннеры показываются постоянно, по очереди.

1. Отредактируйте `site/partners.json` на сайте. Формат описан в файле и в
   `extension/ui/partners.js`.
   - Для каждого баннера обязательны рекламодатель (`advertiser`) и токен маркировки
     `erid`. Его выдаёт CPA-сеть или ОРД.
   - `professions` — кому показывать, например `["маркетолог", "smm"]`. Отбор идёт в
     браузере, профиль никуда не отправляется.
   - `weight` — частота показа.
2. Расширение обновляет список раз в 6 часов. Выпускать новую версию не нужно.
3. Пока файла на сайте нет, показываются встроенные примеры с пометкой «(пример)».

**Статистика баннеров.** Расширение считает показы и клики каждого баннера (только общие
числа, без данных пользователей) и раз в 15 минут отправляет их на сервер бота.
Отчёт с CTR по баннерам и дням:
- в браузере: `https://<сервер бота>/stats?key=<STATS_KEY>`;
- в JSON: `/api/ad-stats?key=…`;
- в Telegram: команда `/stats` из чатов, перечисленных в `ADMIN_CHAT_IDS`.

С этими цифрами можно договариваться с рекламодателями о цене за показ.

Партнёрские ссылки берите в CPA-сетях (например, Admitad) или напрямую у школ и
сервисов. Оплата — за заявку или покупку.

## 5. Telegram: поддержка и уведомления

Подробно — в `bot/README.md`. Коротко:

1. Создайте бота в @BotFather.
2. Запустите `bot/` на сервере (Node 20+ или Docker).
3. Откройте HTTPS-адрес для API.
4. Пропишите `telegram.botUsername` и `telegram.botApi` в `extension/config.js` и
   выпустите обновление. Кнопка «/ поддержка» поведёт в бота, в настройках появится
   «Подключить Telegram».

**Ответы бота.**
- **Без ключа ИИ** бот отвечает разделами базы знаний `bot/knowledge/faq.md`.
- **С ключом Claude API** отвечает своими словами на любые вопросы о solk / job, тоже по
  базе знаний.
- Claude API недоступен из России: сервер бота с ключом размещайте в стране, где
  сервис работает, и оплачивайте картой, которую принимает Anthropic.

## 5а. Резервная копия на Яндекс Диске

1. Зарегистрируйте приложение на oauth.yandex.ru:
   - платформа «Веб-сервисы»;
   - доступ «Яндекс Диск: доступ к папке приложения» (`cloud_api:disk.app_folder`);
   - Redirect URI — по одному на каждый каталог, потому что у расширения в каждом
     каталоге свой id: `https://<id расширения>.chromiumapp.org/`. Id виден на
     browser://extensions после установки из каталога.
2. ClientID впишите в `extension/config.js` → `yandexDisk.clientId` и выпустите
   обновление.

Без ClientID раздел показывается как «скоро». Вход идёт через страницу Яндекса,
пароль расширение не видит. Копия лежит на Диске пользователя, на ваш сервер ничего не
попадает.

## 6. Юридический минимум (согласуйте с юристом)

- **Политика конфиденциальности.** Черновик — `site/privacy.html`; впишите оператора и
  контакты.
  - Резюме и вакансии остаются в браузере пользователя, это сильная сторона продукта.
  - Персональные данные на сервере — только у Telegram-бота (номер чата, имя), и только
    если пользователь сам подключил уведомления.
- **152-ФЗ.**
  - Если обрабатываете персональные данные (бот), подайте уведомление в
    Роскомнадзор.
  - Если вопросы пользователей уходят в иностранный ИИ, это трансграничная передача,
    у неё свои требования.
  - Режим бота «без ИИ» этого вопроса не создаёт.
- **Пользовательское соглашение.** Сервис бесплатный, предоставляется «как есть»;
  пользователь сам соблюдает правила сайтов, с которых собирает вакансии.
- **Налоги с дохода от РСЯ** — по выбранному статусу: самозанятый, ИП или юрлицо.

## 7. Порядок запуска

1. Домен + `site/` на хостинге + политика конфиденциальности.
2. Публикация в Opera Add-ons (бесплатно), затем в Chrome Web Store и Edge.
3. Ссылки на каталоги → `site/config.js`.
4. Бот: @BotFather → сервер → `extension/config.js` → обновление 0.9.x.
5. Аудитория сайта → заявка в РСЯ → письменное согласование схемы с фреймом →
   `ads.mode: 'rsya'`.
6. Каждое обновление: версия ↑ → `npm run pack` → загрузка в каталоги.
