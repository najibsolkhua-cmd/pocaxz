# Публикация solk / job в каталогах браузеров

Всё для публикации лежит здесь:
- `store/listing.md` — тексты описания;
- `store/img/` — скриншоты 1280×800 и промо-картинки 440×280 и 1400×560;
- архив для загрузки собирает `npm run pack` → `dist/solk-job-<версия>-store.zip`.

Отправить расширение может только владелец аккаунта разработчика: каталоги требуют
вашу личность, телефон или оплату. Порядок действий для каждого каталога ниже.

| Браузер | Каталог | Как попадает к пользователям |
|---|---|---|
| **Яндекс Браузер** | Opera Add-ons или Chrome Web Store | Своего каталога для отправки у Яндекса нет. Яндекс Браузер ставит расширения из Opera Add-ons (кнопка «Добавить в Яндекс Браузер») и из Chrome Web Store. |
| **Opera** | Opera Add-ons | напрямую |
| **Google Chrome** | Chrome Web Store | напрямую |
| **Microsoft Edge** | Edge Add-ons | напрямую (Edge умеет ставить и из Chrome Web Store) |
| **Firefox, Safari** | — | Пока не поддерживаются: в них другой движок расширений (нет фонового service worker и offscreen-документов из Chrome). Нужна отдельная версия, см. «Что можно улучшить». |

Обновления: увеличьте `version` в `extension/manifest.json` → `npm run pack` → загрузите
новый архив в каждый каталог. После модерации браузеры обновят расширение у всех сами,
данные пользователей сохраняются.

---

## 1. Opera Add-ons (бесплатно) — главный путь в Яндекс Браузер

1. Войдите в addons.opera.com/developer под аккаунтом Opera.
   Создать аккаунт: auth.opera.com, бесплатно.
2. «Upload new extension» → загрузите `dist/solk-job-<версия>-store.zip`.
3. Заполните карточку:
   - **Name:** solk / job — поиск работы
   - **Summary** и **Description:** из `listing.md` (русский — основной язык).
   - **Category:** Productivity.
   - **Screenshots:** `store/img/screenshot-*.png`.
   - **Icon:** `extension/icons/icon128.png`.
   - **Homepage:** https://solkhua.ru/
   - **Privacy policy:** https://solkhua.ru/privacy.html
   - **Support:** ссылка на бота поддержки или https://t.me/max_max3700
   - **Source code:** если модератор попросит — код в репозитории, без сборщиков и
     минификации (кроме pdf.js в `vendor/`, это официальная сборка Mozilla).
4. Отправьте на модерацию. Обычно от нескольких дней до пары недель. Модераторы
   могут задать вопросы о разрешениях: ответы — в `listing.md`, раздел
   «Зачем разрешения».
5. Ссылку на страницу расширения впишите в `site/config.js` → `stores.opera`.

## 2. Chrome Web Store ($5 один раз)

1. Откройте chrome.google.com/webstore/devconsole.
   - Нужен аккаунт Google и разовая оплата $5.
   - Российские карты Google, как правило, не принимает: нужна карта другой страны.
2. «New item» → загрузите тот же архив.
3. Вкладки карточки:
   - **Store listing:** описание из `listing.md`, категория Productivity, язык Russian,
     скриншоты, промо 440×280 (`promo-small.png`) и 1400×560 (`promo-marquee.png`).
   - **Privacy:**
     - single purpose — из `listing.md`;
     - обоснование каждого разрешения — из `listing.md`;
     - «Does not collect or use data» не подходит, если включены Telegram-уведомления.
       Отметьте «Personally identifiable information» (номер чата Telegram) и укажите,
       что данные не продаются и используются только для функции.
     - ссылка на политику.
   - **Distribution:** Public, все регионы.
4. Отправьте на проверку. Расширения с доступом ко всем сайтам проверяют дольше,
   обычно несколько дней.
5. Ссылку впишите в `site/config.js` → `stores.chrome`.

## 3. Microsoft Edge Add-ons (бесплатно)

1. Зарегистрируйтесь в partner.microsoft.com → программа Microsoft Edge. Бесплатно.
2. «Create new extension» → загрузите тот же архив.
3. Описание, скриншоты, ссылка на политику — те же. Категория Productivity.
4. Ссылку впишите в `site/config.js` → `stores.edge`.

## 4. После публикации

- **Ссылки на каталоги** — в `site/config.js`. После этого кнопка на сайте ставит
  расширение в один клик.
- **Реклама расширения:** давайте ссылку на сайт https://solkhua.ru/. Сайт сам
  отправит человека в нужный каталог.
- **Каталог «Дополнения» Яндекс Браузера** — курируемый, отдельной формы для него нет.
  Когда наберутся пользователи и отзывы в Opera Add-ons, можно написать в поддержку
  Яндекс Браузера с предложением добавить solk / job в подборку.
