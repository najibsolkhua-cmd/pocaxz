## Название
solk / job — поиск работы

## Краткое описание (до 132 символов)
Собирает вакансии с hh.ru, Avito, Telegram и сайтов компаний и показывает подходящие вашему резюме. Бесплатно.

## Полное описание

solk / job — бесплатная CRM для поиска работы прямо в браузере.

Загрузите резюме, и solk / job:
• сам заполнит профиль: должность, навыки, город, зарплату;
• настроит поиск на hh.ru и Avito по вашей должности;
• соберёт вакансии из Telegram-каналов и с любых сайтов компаний (rabota.ru, superjob.ru, карьерные сайты банков и компаний), сам впишет должность и город в поиск на сайте;
• оценит каждую вакансию — «Подходит мне 87%» — и объяснит почему: должность, навыки, опыт, зарплата;
• отсеет чужие города, должности и старые вакансии;
• поможет не терять отклики: статусы «Откликнулся», «Отправил резюме», «Интервью», «Оффер», заметки;
• сопроводительное письмо под каждую вакансию собирается само из вакансии и вашего профиля: одна кнопка — и оно в буфере обмена, осталось вставить на сайте (Ctrl+V / ⌘ Cmd+V);
• напомнит о следующем шаге: «7 дней без ответа — напишите рекрутеру», «Интервью завтра — подготовьтесь» (в браузере и в Telegram);
• сохранит всё на ваш Яндекс Диск и перенесёт на новый компьютер.

Поиск идёт в вашем браузере, с человеческой скоростью. Можно запускать вручную или по расписанию. Есть таймер, кнопка «Стоп» и несколько профилей для разных профессий. Уведомления — в браузере и в Telegram.

Конфиденциальность: резюме, профиль и вакансии хранятся только в вашем браузере и никуда не отправляются.

solk / job бесплатный. Во время работы показывается реклама партнёров и Рекламной сети Яндекса — так проект остаётся бесплатным для всех.

## Single purpose (Chrome Web Store)
Поиск работы: сбор вакансий с сайтов, которые выбрал пользователь, оценка их соответствия резюме и учёт откликов.

## Зачем разрешения

| Разрешение | Зачем |
|---|---|
| Доступ ко всем сайтам (host permissions) | Пользователь сам добавляет любые сайты с вакансиями (hh.ru, Avito, t.me, карьерные сайты компаний). Расширение открывает эти страницы и читает список вакансий. Другие сайты не читаются. |
| tabs | Открыть страницу выдачи в фоновой вкладке и закрыть её после чтения. |
| scripting | Прочитать вакансии на открытой странице выдачи и вписать должность и город в поле поиска сайта. |
| storage, unlimitedStorage | Хранить профиль, резюме, вакансии и статусы откликов локально, без ограничения объёма. |
| alarms | Поиск по расписанию, которое задаёт пользователь. |
| notifications | Сообщить о новых подходящих вакансиях. |
| idle | Не запускать поиск, пока экран заблокирован (настройка). |
| activeTab | Кнопка «Собрать вакансии с этой вкладки». |
| offscreen | Разобрать страницу без вкладки, если браузер не пускает расширения на сайт (сайты банков в защищённом режиме). |
| identity | Вход в Яндекс для резервной копии на Яндекс Диске (по желанию пользователя, доступ только к папке приложения). |
| clipboardWrite | Скопировать сопроводительное письмо в буфер обмена по кнопке «Скопировать письмо» — пользователь сам вставляет его на сайте. |

## Реклама (раскрытие)
Расширение показывает рекламу только в собственном интерфейсе: баннеры партнёров и блок
Рекламной сети Яндекса. Каждое объявление помечено «Реклама» и названием
рекламодателя. В чужие сайты реклама не встраивается, ссылки на сайтах не подменяются.
